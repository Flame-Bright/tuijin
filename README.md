# 推进

> 把模糊的事，推进一步。

一个本地运行的桌面进度管理程序：把想做的事写下来，给它设一个完成度，再拆成几个能真正开始的小节点。左边是工作台，右边是一张可以一直放在桌面上的进度卡片。

> **要用代码改这个项目？** 先读 [AGENTS.md](AGENTS.md)（架构与边界）和 [开发指南.md](开发指南.md)（构建与环境）。

## 直接运行

双击：

```
release\推进\推进.exe
```

这是自包含版本，不需要安装 .NET；Windows 10/11 需要 WebView2 运行时（Windows 11 已内置）。

程序优先把数据放在 `%APPDATA%\Tuijin`。如果所在目录不允许写这个位置（例如放在某些受限目录里运行），会自动改用程序旁边的 `userdata` 文件夹，仍然可以正常启动。

如果 Windows 第一次运行时提示“Windows 已保护你的电脑”，选择「更多信息」→「仍要运行」。程序没有代码签名，这是正常提示。

第一次启动会同时打开工作台和桌面浮层，并创建一张示例任务。之后启动只会显示桌面浮层，方便把它留在桌面上。示例任务可以直接改标题，也可以删除。

> 桌面浮层出不出来，看的是「球的开关」。上次关掉的话，这次启动就不会有球，按 `Alt + Shift + D` 或从托盘菜单打开。

## 桌面浮层

桌面上那个小东西有两种样子，都在「外观」里切换：

**悬浮球**（默认，圆形）
- 一圈进度环 + 中间大号百分比 + 「N 件在推」。
- 全部完成时，环和数字会转成绿色。

**卡通人**（竖长）
- 一个手绘感的小人，会跟着总进度换表情和动作：
  - 0% —— 摊在地上躺平，「先躺一会儿」
  - 1–40% —— 撑着地坐起来
  - 41–80% —— 使劲推一个大球，「正在使劲」
  - 81–99% —— 踮脚去够星星
  - 100% —— 蹦起来撒彩纸，「全都成了」

**自己的图**（竖长，和卡通人同尺寸）
- 换一张你自己的图片：工作台「外观 → 桌面形态 → 自己的图」，点「选择图片…」。
- 图片会铺满整个小人，自动缩放压缩后存到数据目录（不动你原来的文件）。
- 两个调节：**铺满 / 完整**（cover 裁切或 contain 完整显示）、**压暗**（0–60%，字更清楚）。
- 不想在图上看进度？关掉「显示进度和文字」，就只剩一张干净的图。
- 没选图时会自动显示成卡通人，不会出现破图。

**大小**：三档可选（小 / 中 / 大），默认是最小那档。悬浮球小档直径 116，大档 168；卡通人按同样比例。

两种形态都可以：

- 按住主体拖动到任意位置（位置自动记住）。
- **点一下 → 展开成完整详情面板**，里面能看概览、切进行中 / 已完成、勾节点、快速添加。
- 展开后点右上角向下的箭头 → 收回原来的样子。
- 右键或长按（展开态）可以出菜单。
- `Alt + Shift + D`：随时呼出 / 收起桌面浮层（全局快捷键，等同于切换「球的开关」）。
- 托盘图标右键：打开 / 隐藏桌面浮球、打开工作台、切换桌面形态、浮层大小、置顶、回到屏幕右侧、打开数据文件夹、退出。

## 球的开关

球和工作台**可以同时存在**，各用各的。要不要在桌面上放球，由你决定：

- 工作台「外观 → 桌面形态」里有一个 **「在桌面显示悬浮球」** 开关。
- 关掉后桌面上就干净了，工作台照常可用；想叫回来，打开开关，或按 `Alt + Shift + D`，或点托盘图标右键 →「显示桌面浮球」。
- 开关状态会记住，重启后保持不变。
- 以前「工作台最大化就自动把球藏起来」的行为已经去掉 —— 现在两个窗口互不干扰。

> **被别的窗口挡住看不见？**
> 这是「始终显示在其他窗口上方」被关掉了——它没丢，只是排到了后面。
> 从托盘图标点一下，或者按 `Alt + Shift + D` 就能叫回来。
> 工作台「外观」面板里有这个开关，展开浮层时如果没开，顶部也会显示一行提示，点「开」直接打开。

## 功能

- **随时添加**：主界面输入框、桌面卡片底部输入框，按 `Enter` 即可添加。
- **完成度**：
  - 拖动滑块手动设置 0–100%；
  - 有节点时可以开启「按节点自动计算」，勾选节点后自动更新进度。
- **节点**：
  - 为每件事添加多个具体小节点；
  - 节点可以单独设置截止日期；
  - 勾选即完成，删除节点也不会影响其他内容。
- **更多**：
  - 工作 / 生活 / 学习 / 灵感分类；
  - 任务截止日期、备注、搜索、分类筛选、排序；
  - 进行中 / 已完成视图，完成后可以重新打开；
  - 浅色 / 深色主题；
  - 所有数据保存在本机，不上传网络。

## 外观

工作台侧栏底部点「外观与字号」（或按 `Ctrl +`）打开外观面板，改动立刻生效并保存。

**字号**：觉得字小就调大，觉得拥挤就调小。
- 滑块 80% – 160%，步进 5%；也提供 90% / 100% / 115% / 130% 四档快捷芯片。
- 工作台和桌面浮层会**同时**跟着缩放。
- 侧栏底部还有一条「− 字号 xx% +」的快捷条，随手就能调。

**主题**：浅色 / 深色。

**强调色**：陶土 / 鼠尾草 / 海蓝 / 梅紫 / 琥珀 / 墨灰，影响按钮、进度环、选中态的颜色。

**桌面形态**：悬浮球 / 卡通人 / 自己的图（见上一节）。

**在桌面显示悬浮球**：球的开关。关掉后桌面上不再出现浮层，工作台照常使用；`Alt + Shift + D` 或托盘菜单都能再打开。开关状态会保存。

**浮层大小**：小 / 中 / 大三档。悬浮球直径分别是 116 / 148 / 168。

**始终显示在其他窗口上方**：开着就一直浮在最前；关掉则会正常参与窗口层级，被别的软件挡在后面。

**壁纸**：
- 三种来源：无 / 预设 / 自定义图片。
- 8 个预设：日出、黄昏、林间、海面、纸感、夜色、渐层、网点，每个都有对应的暗色版本。
- 自定义：点「选择图片…」选一张本地图片，程序自动缩放压缩后存到数据目录（不会改动你原来的文件）。
- 两个调节：**压暗**（0–80%，壁纸太花时压暗一点，字更清楚）、**模糊**（0–24）。
- 勾选「壁纸也铺到这个工作台」，工作台也会用同一张壁纸。

面板底部「恢复默认外观」可以一键复原。

## 窗口

工作台是**无边框窗口**：

- 顶部标题栏区域可以按住拖动整个窗口。
- **把鼠标移到任意一边或任意一角，光标会变成缩放箭头，按住拖动即可自由改变大小**，不再只有「正常」和「全屏」两种。
- 最小可以缩到大约 360×320；窗口变窄时侧栏会自动收成图标条，内容跟着重排。
- 右上角三个按钮：最小化、最大化 / 还原、收起到托盘。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `N` | 把光标放到「新建一件事」输入框 |
| `Ctrl + K` | 搜索任务 |
| `Ctrl +` / `Ctrl -` | 放大 / 缩小界面字号 |
| `Ctrl + 0` | 字号恢复 100% |
| `Esc` | 关闭详情 / 弹窗 |
| `Alt + Shift + D` | 呼出 / 收起桌面浮层（切换球的开关） |

## 数据在哪里

```
%APPDATA%\Tuijin\data.json
```

每次保存会生成 `data.json.bak` 备份。换电脑时复制 `data.json` 即可。

自定义壁纸存在 `%APPDATA%\Tuijin\wallpaper\`，换电脑时需要连同这个文件夹一起复制。

桌面小人的自定义图片存在 `%APPDATA%\Tuijin\widget-custom\`，同样要一起复制。

如果 `%APPDATA%` 不可写，数据会改存到程序目录下的 `userdata\roaming\data.json`，缓存（WebView2）同样在 `userdata\local`。

托盘菜单里的「打开数据文件夹」可以直接打开这个位置。

## 从源码构建

需要 .NET 9 SDK、WebView2 Runtime。

```powershell
dotnet publish native\Tuijin\Tuijin.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=false -o release\推进
```

`native\NuGet.config` 使用仓库里的本地包目录 `.nuget-local`，方便离线构建；如果删除了这个目录，把 NuGet 源改回 `nuget.org` 即可。
